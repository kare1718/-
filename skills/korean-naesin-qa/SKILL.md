# 국어 내신 자료 검수 — 학교 무관 공통 기준

내신 자료는 어느 학교든 같은 다섯 기준으로 검수한다. 학교마다 다른 것(학년별 작품 배정·허용 예외·판별 마커)은 `references/<학교>.md`에 있다. **자료를 만들 때든 검수할 때든, 먼저 해당 학교의 참조 파일부터 읽는다.** 등록되지 않은 학교면 아래 '학교 추가'를 따른다.

## 공통 검수 기준 5가지

1. **학년·과목 혼입** — 그 학교 배정표 기준으로, 다른 학년에 배정된 작품이 문서에 섞이면 안 된다. 특히 예시·'이 시험 작품' 칸. 단, '외부지문 예측'에는 다른 학년 작품이 비교용으로 올 수 있다 — '이 시험 작품의 예'에만 엄격히 적용한다.
2. **인용 출처** — 시구·구절의 작가·작품이 실제와 일치해야 한다. 학교 참조 파일의 '출처 주의' 목록을 확인하고, 확신 없는 인용은 검색으로 검증한다.
3. **문어체 톤** — 산문은 '~다/~이다/~한다'로 통일. '습니다/세요/대화체'는 원문 인용·문법 예시(상대높임 종결형 표 등)에서만 허용.
4. **빌드 무결성** — 널바이트·구문 오류 0건. 하나라도 있으면 고친 뒤 재검수.
5. **레이아웃** — 제목이 페이지 하단에 혼자 남지 않고(keepNext), 문단이 페이지에 걸쳐 쪼개지지 않게(keepLines). 표지·푸터에 학교·학년·과목 표기.

## 검수 절차

1. 자료가 어느 학교 것인지 확인하고 `references/<학교>.md`를 읽는다.
2. 자동 검수기 실행 — 학교·학년은 파일 내용으로 자동 판별되며, 안 되면 `--학교`로 지정한다.

```
python3 검수.py                    # 현재 폴더의 build*.js 자동
python3 검수.py 파일1 파일2         # 파일 직접 지정
python3 검수.py --학교 계성고 파일   # 학교 자동 판별이 안 될 때
```

- **학년 혼입 · 널바이트 · 구문 오류는 반드시 0건.** (통과 시 종료 코드 0, 문제 시 1)
- **검토후보**(습니다/세요, 「」 짝 불일치)는 원문 인용·문법 예시면 통과, 그 외 산문이면 문어체로 고친다.

3. 자동 검수기가 못 잡는 것을 손으로 확인한다: 인용 출처(기준 2), 레이아웃(기준 5), 학교·학년 표기.

## 학교 추가·수정

새 학교의 자료나 작품 목록을 받으면:

1. `references/_학교_양식.md`를 복사해 `references/<학교>.md`를 작성한다.
2. `검수.py`의 `SCHOOLS` 딕셔너리에 같은 내용(마커·학년마커·작품·허용)을 등록한다.
3. **두 곳은 항상 함께 고친다.** 참조 파일과 검수기가 어긋나면 그 틈이 그대로 검수 구멍이 된다. 작품 하나를 옮길 때도 양쪽을 같이 수정한다.

작품 목록이 명시적으로 주어지지 않았다면, 받은 자료(기출·프린트)에서 학년별 작품을 추출해 배정표 초안을 만들고 사용자에게 확인받은 뒤 등록한다.
