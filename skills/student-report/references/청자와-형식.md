# 청자 4종 · 보고서 유형별 형식

## 청자별 프레이밍

**학부모** — "학원의 강사가 학부모에게 자녀의 학습 현황을 전하는 공식 상담 편지"
- 톤: 따뜻하고 신뢰감 있으며 정중한 격식체(~습니다). 부모 마음을 헤아리는 표현.
- 다음 단계 제안: 가정에서 도울 수 있는 습관·환경·정서적 지지 1~2개(정해진 시간·공간 마련, 오답 정리한 날 격려, 제출 여부 가볍게 확인) + 학원에서 집중 관리하겠다는 안내 1개. **학부모에게 문법·독해 등 학습 내용을 직접 설명·지도하게 시키지 않는다 — 그건 학원의 몫.**
- 안전선: 다른 학생·강사 비교 금지, 내부 메모 원문 인용 금지(핵심만 요약), 학습 성향은 단정적이지 않게.
- 학부모 문서에서 빼는 것: 수납, 게이미피케이션, 문자 통계, 요일 패턴 같은 운영 지표 — 학습 이해에 도움이 안 되는 노이즈.

**학생** — 화면에 실리는 문구와 대화를 구분한다.
- 화면 문구(리포트·코멘트): 정제된 격식체(~합니다/~해 보세요), 과장·느낌표 없이 담백. 우수한 점은 숫자로 짚고, 아쉬운 점은 판단하지 말고 구체 제안으로("다음 주는 과제를 하루 먼저 시작해 보세요").
- 대화(질문에 답할 때): 학생 말투를 따라간다.
- 등수는 언급하되 경쟁 압박 최소화. 학부모 상담 내용 언급 금지.

**강사(동료)** — "동료 선생님이 참고할 학생 분석 노트"
- 전문적·간결·실무적, 수치 중심. 친근한 존댓말("~이에요") 가능. 데이터에 보이면 단정적으로 쓴다("~할 것 같다" 최소화).

**원장(운영)** — "월요일 아침 커피 한 잔 들고 2분 안에 훑는 브리핑"
- 사실 기반: 통계에 없는 내용은 추측하지 않는다. 모든 주장에 수치, 가능하면 전주 대비·목표 대비.
- 짧고 단정적. "전반적으로 양호합니다" 금지 — 구체적 행동 지시로.

## 유형 1 — 학생 종합 보고서 (학부모 공유용이 기본)

서술 구조(순서대로):
1. 종합 평가 — 관통 스토리 3~4문장, 구체 수치 1개 이상
2. 강점 2~3 / 보완점 2~3 (수치 근거 + 원인 가설)
3. 영역별 정답률 해설 (영역명 + 정답률 + 의미 한 줄)
4. 자주 틀리는 패턴 (패턴 + 가설)
5. 학습 성향 (태그 + 60~120자)
6. 처방 — 단기(2~4주)/중기(1~2개월)/시험 직전, 각각 빈도·시간·분량 명시
7. 이렇게 지도하고 있습니다 (실제 지도 활동 3~4문장)
8. 학습 로드맵 (현재 위치 → 다음 목표 → 중간 단계 2~3)
9. 다음 단계 (청자가 할 일 — 학부모면 습관·환경·격려)
10. 전달 메시지 (문자용 2~3문장)

유형 변형: 월간 종합(30일) / 시험 후 분석(실점 유형·다음 시험 대비 집중) / 상담용(그래프·메모 중심, 90일) / 학부모 간단(1페이지: 핵심 수치+강점+다음 계획, 14일) / 관리 강화(학원의 적극 관여 부각) / 신규 입반 초기 진단(현재 수준+약점+첫 계획, 14일).

## 유형 2 — 학생 질문(대화) 분석 · 약점 진단 (강사용)

출력은 이 4섹션 마크다운만:

```
## 강한 영역
- 자신감 있게 묻거나 만족도 높은 영역 1~3개 (구체 작품·개념 인용)

## 약한 영역
- 자주 막히거나 부정 평가 누적 영역 1~3개 (구체 작품·개념 인용)
- 같은 개념 반복 질문은 명시 ("X에 대해 N회 질문 → 미정착")

## 자주 막히는 패턴
- 작품 분석/문법 개념/시간·전략 중 어디서 막히는지 분류
- "추상→구체 연결 약함" 같은 학습 패턴 진단

## 추천 학습 방향
1. 가장 시급한 보완 (구체 액션 — 어떤 작품·개념·기출)
2. 두 번째 우선순위
3. 강사 면담 시 짚을 포인트 1개
```

원칙: 추측·일반론 금지, 질문 데이터 근거만. 전체 400~700자. 친근한 존댓말(강사용). 학생 이름은 본문에 반복하지 않는다.

## 유형 3 — 주간 학생 진단 (학생 화면용)

"이번 주 데이터를 보고 다음 주 계획을 잡아주는 코치" 역할. 정제된 격식체, 과장·느낌표 없이. 수치를 나열하지 말고 의미로 풀되, 성적·점수 수치는 직접 쓰지 않는다. 각 1~2문장:
- **방향**: 다음 주 공부 방향
- **약점**: 지금 가장 집중할 약점
- **미션**: 이번 주 복습 미션 (구체 행동)

## 유형 4 — 주간 운영 브리핑 (원장용)

- **헤드라인** 13~28자, 핵심 수치 포함: "출결 98% 안정, 과제 제출률 70%로 3주 연속 하락"
- **요약** 3~4문장: (1) 전반 상태+핵심 수치 (2) 잘된 점의 근거 (3) 개선 필요점+원인 가설+권장 방향
- **주의 학생** ≤5명 (이유에 수치+행동: "과제 2주 연속 미제출 + 결석 3회. 화요일 중 학부모 통화로 사유 확인 필요.")
- **실행 항목** ≤5 ("과제 부진 상위 5명 학부모에게 수요일까지 SMS 발송")
- **긍정 신호** ≤3 / **다음 주 관찰 포인트** ("과제 제출률 반등 여부 — 독려 SMS 효과 가늠 지표")
