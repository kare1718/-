# 작성 원칙 상세 · 예문 · 금지 목록

## 목표 품질 예문 (이 수준을 벤치마크로)

- **종합 평가(overall)**: "이번 달 OO는 출결 100%(20회 무결석)와 과제 94%(16/17)로 학습 루틴이 안정적입니다. 다만 5월 모의에서 독서 영역 정답률이 52%로 문학(85%) 대비 크게 낮아, 비문학 지문의 정보 구조 파악이 다음 한 달의 핵심 과제로 보입니다. 4월 대비 전체 평균은 +6점 상승해 방향은 분명히 옳습니다."
- **보완점**: "독서(비문학) 정답률 52% — 특히 과학·기술 지문에서 매력적 오답을 반복 선택(5/12, 5/19 시험 공통). 문장 간 논리관계(인과·대조)를 표시하며 읽는 훈련이 필요합니다."
- **처방(단기)**: "월·수·금 비문학 지문 1개씩 — 문단별 핵심어 표시 후 문단 간 관계를 화살표로 연결하는 '구조도 그리기' 10분."
- 핵심: 영역명·정답률·날짜·문항 유형까지 구체적으로. 학부모가 "이 정도면 우리 아이를 정말 분석했다"고 느끼게.

## 나쁜 문장 (즉시 삭제 대상)

- "전반적으로 양호합니다" / "관리가 필요합니다" (무엇을·어떻게가 없음)
- "꾸준히 노력하는 모습이 인상적입니다" / "앞으로도 기대됩니다" (정보 없음)
- "아마 시험기간이라…" (데이터에 없는 추측)
- "매우", "정말", "굉장히" (빈 강조어)

## 데이터 근거의 우선순위

1. 시험: 원점수/만점 + 학급평균 대비 + 전회 대비 변화. 응시자 3명 미만이면 학급 통계는 쓰지 않는다.
2. 영역별 정답률(화법과 작문 / 문학 / 독서 / 문법 / 언어와 매체) + 자주 틀리는 영역 Top 3 + 오답 유형 가설.
3. 출결·과제: 비율 + 내역("결석 0, 지각 1", "4/17 과제만 누락").
4. 학생이 스스로 남긴 질문 — "이 학생만의 이야기"를 만드는 최고의 근거. 데이터가 있으면 1회 인용한다. 예: "비음화를 스스로 질문할 만큼 문법 개념에 관심이 붙었습니다."
5. 클리닉 참여·선생님 총평, 선생님 메모, 상담 기록(학부모 문서에는 원문 인용 금지, 핵심만 요약).

## 강점·보완·처방의 역할 분담 (반복 방지)

- **종합 평가** = 전체를 관통하는 핵심 스토리 1개 (개별 항목 나열 금지)
- **강점/보완점** = 종합 평가에 없는 구체 항목들 (각 2~3개, 수치 근거)
- **다음 단계(next_steps)** = 청자가 할 일 / **처방(action_plan)** = 학생·학원이 할 일 — 주체가 다르다. 같은 내용이면 한쪽을 재작성.
- **처방 3단**: 단기(2~4주) / 중기(1~2개월) / 시험 직전.
- **학습 성향** = 진단명이 아니라 사람을 소개하듯: 한 구절 태그 + 60~120자 설명.
- **지도 요약(guidance)** = 학원이 이번 기간 이 학생을 어떻게 지도했는지 — 실제 데이터가 있는 활동만.
- **로드맵** = 현재 위치 → 다음 목표 → 중간 단계 2~3개.
- **전달 메시지** = 학부모 문자용 2~3문장 — 보고서 요약 재탕이 아니라 "리포트를 확인해 주세요" 안내가 본질. 격식체, 이모지 금지.

## 금지 목록 (전체)

- 다른 학생 이름·학생 간 비교 일체 금지.
- 의학·심리 진단(ADHD·학습장애·불안장애 등) 금지. 건강·정서 이상 신호가 보이면 학습 조언은 가볍게 하고 "선생님·전문가와 상담"을 안내한다.
- 학생의 성격·의지·능력 단정("게으르다", "의지가 약하다") 금지.
- 학부모·학생에게 보이는 문서에 'AI'·'인공지능'·'AI 학습조교' 표기 금지.
- 학부모 이름 호명 금지("○○○ 어머님" ✗) — "○○ 학생 학부모님".
- 이모지: 학부모 문서 금지. 학생 화면 문구는 담백하게(필요 시 1~2개까지만).
- 느낌표·응원단 톤("~해보자!", "~할 기회!") 금지 — 담백하고 정제되게.
- 질책·강압("반드시", "즉시") 자제. 수강료 언급은 학습 보고서에서 제외.
- 문자(SMS)류: 장문 요약 금지 — 핵심 성과/이슈 한 줄 + 확인 부탁 한 줄.
