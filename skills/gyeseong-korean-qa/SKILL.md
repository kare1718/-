# 계성고 국어 자료 검수

계성고 고1(공통국어1)·고2(문학) 자료를 만들거나 고친 뒤, 배포 전에 이 절차로 검수한다.

## 1. 자동 검수기 실행

같은 폴더에 있는 `검수.py`를 소스 파일과 함께 두고 실행한다.

```
python3 검수.py            # 생략 시 build6.js(고1)·build7.js(고2) 자동
python3 검수.py 파일1 파일2  # 파일을 직접 지정
```

- **학년 혼입 · 널바이트 · 구문 오류는 반드시 0건.** 하나라도 뜨면 고친 뒤 재검수.
- **검토후보**(습니다/세요, 「」 짝 불일치)는 원문 인용·문법 예시(예: '아아, 님은 갔습니다', 상대높임 종결형 표)면 통과, 그 외 산문이면 문어체로 고친다.

## 2. 학년별 작품 배정표  (※ 교육과정 따라 수정 가능)

**1학년 — 공통국어1**
- 문법: 단어와 품사 / 단어의 짜임 / 문장 성분 / 문장의 짜임 / 문법 요소(높임·시간·피동·사동·부정)
- 고전시가(시조): 어부단가(이현보), 만흥(윤선도), 오륜가(김상용), 저곡전가팔곡(이휘일), 강호사시가, 도산십이곡, 고산구곡가, 훈민가, 단심가·하여가, 회고가, 황진이 시조
- 고전시가(가사): 상춘곡, 사미인곡·속미인곡·관동별곡·성산별곡(정철), 누항사, 규원가, 농가월령가
- 현대시: 정호승 「내가 사랑하는 사람」·「슬픔이 기쁨에게」, 백석 「선우사」, 황진이 「동짓달 기나긴 밤을」, 윤하 「사건의 지평선」, 신경림 「가난한 사랑 노래」, 정희성 「저문 강에 삽을 씻고」
- 비문학: 경제·선거·동물 복지

**2학년 — 문학**
- 갈래: 극(가면극) · 교술(설·기·가전) · 서정 · 서사
- 현대시: 윤동주 「참회록」·「서시」·「별 헤는 밤」(·「십자가」), 김수영 「어느 날 고궁을 나오면서」, 신동엽 「누가 하늘을 보았다 하는가」, 김소월 「길」
- 극: 「통영 오광대」·「봉산탈춤」  ·  교술·가전: 「주옹설」(권근)·「공방전」(임춘)
- 서사: 「엄마의 말뚝 2」(박완서), 「부용전」
- 허용(2학년 중간고사 실제 사례): 「어부사시사」(교과서) ↔ 이현보 「어부가」(외부)

> 핵심: **어부단가·정호승·사미인곡·속미인곡 = 1학년.** 윤동주 세 편·고궁·하늘·통영/봉산·주옹설·공방전·김소월 「길」 = 2학년. 서로 넘나들지 않게 한다. 단, '외부지문 예측'에는 다른 학년 작품이 비교용으로 올 수 있으나 '이 시험 작품의 예'에는 해당 학년 작품만 넣는다.

## 3. 손으로 확인할 것

1. **학년 분리** — 위 배정표대로. 특히 예시·'이 시험 작품' 칸.
2. **인용 출처** — 시구·구절의 작가·작품이 맞는가. ('가마귀 가왁가왁'=김소월 「길」, '무심코 다정한 것'=이현보 어부단가=1학년)
3. **문어체 톤** — 산문은 '~다/~이다/~한다', '습니다/세요/대화체' 금지(원문·예시 제외).
4. **레이아웃** — 제목이 페이지 하단에 혼자 남지 않고(keepNext), 문단이 페이지에 걸쳐 쪼개지지 않게(keepLines).
5. **학년 표시** — 표지·푸터에 학년·과목 표기.

## 4. 배정표 수정

작품을 추가·이동하려면 `검수.py`의 `G1_ONLY` / `G2_ONLY` 목록을 고친다.
