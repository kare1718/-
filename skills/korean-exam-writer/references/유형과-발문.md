# 문항 유형 · 정형 발문 · 세트 구성 · 난이도

## 유형 목록

문학 풀세트 / 비문학 풀세트 / 문법 풀세트 / 수능형 문항 / OX 문제 / 표현상의 특징 / 시어·구절 이해 / 시상 전개 방식 / <보기> 문항 / 어휘 확인 문제 / 서술형 / (가)(나) 비교 / (가)(나)(다) 비교

## 유형별 정형 발문 (이 목록에서만 고른다)

- **표현상의 특징**: "윗글에 대한 설명으로 (가장) 적절한 것은?" / "윗글의 표현에 대한 설명으로 적절하지 않은 것은?"
- **시어·구절 이해**: "윗글의 ㉠~㉤에 대한 이해로 적절하지 않은 것은?"
- **시상 전개**: "윗글의 시상 전개에 대한 설명으로 가장 적절한 것은?"
- **문학 <보기>**: "<보기>를 바탕으로 윗글을 이해한 내용으로 적절하지 않은 것은?"
- **비문학 <보기>** (방향이 반대다): "윗글을 바탕으로 <보기>를 이해한 내용으로 적절한 것은?"
- **비문학 일반**: "윗글의 내용과 일치하는(일치하지 않는) 것은?" / "윗글에 대한 이해로 적절하지 않은 것은?" / "윗글의 내용을 바탕으로 추론한 것으로 적절한 것은?"
- **어휘**: "윗글의 밑줄 친 '단어'와 가장 가까운 의미로 사용된 것은?" / "윗글의 ⓐ~ⓔ의 사전적 의미로 적절하지 않은 것은?"
- **서술형**: "윗글에서 화자의 정서 변화를 서술하시오." 계열
- **비교**: "(가)와 (나)의 공통점으로 가장 적절한 것은?" — 비교 문항의 선지는 (가)·(나)를 모두 언급해야 한다.

## 풀세트 구성 (순서 고정)

**문학 단독 5문항**
1. 표현상 특징 / 서술상 특징
2. 시어·구절·장면의 기능 판단
3. 정서·인식·태도 흐름 파악
4. <보기> 관점 적용
5. 고난도 종합 감상 / 외부 작품 연계 / 학생 감상문 평가

**문학 비교 세트(갈래 복합)**: 위 5문항 중 3개를 작품 간 비교 또는 [A]/[B] 부분 비교로 교체.

**문학 7문항**: 위 5 + 6번(외부 작품 연계 <보기>) + 7번(고난도 종합 감상 / 학생 감상문 평가 / 관계 판단형).

**비문학 5문항**
1. 내용 전개 방식·구조 파악
2. 세부 정보 이해(내용 일치/불일치)
3. 전체 내용 바탕 심층 이해·추론
4. 특정 구절 인용형 추론(발문 바로 아래 인용 제시)
5. <보기> 사례 적용·심화
- 비문학 <보기>는 줄글 문단 최대 3개, 소제목 없이 길이감 있게. 카테고리형·개조식 금지.

**문법 3문항**
1. 지문 내용 적용형 — 지문 기준을 <보기>의 ㉠~㉤ 사례에 적용
2. 분류·비교형
3. 확장 추론형 — 지문에 없는 새 사례를 지문 원리로 추론
- <보기>는 ㉠~㉤으로 자료 5개를 줄 단위 명시(지문이 아니라 <보기> 박스 안에).
- 어려운 어휘로 난이도를 올리지 말 것. 고1이 아는 단어·문장으로, 형태소 경계·문장 구조·기능 차이·적용 조건·예외 판단을 동시에 따지게 해 난이도를 올린다.
- 문법은 지문이 없으면 직접 작성해도 되는 유일한 유형이다.
- 문법 문항에는 문법 전문 용어 금지 규칙이 적용되지 않는다.

## 난이도 5단계 (목표 정답률 기준)

| 라벨 | 목표 정답률 | 선지 길이 | 특징 |
|---|---|---|---|
| 최상 | 3~10% | 55~75자 | 지문 4번 이상 정독 요구 |
| 상 | 5~15% | 50~70자 | 특목고 킬러 문항 수준 |
| 중 | 20~30% | 40~60자 | 상위 5~10% |
| 하 | 35~50% | 35자 이상 | 수능 본시험 평균 |
| 최하 | 55~65% | 30자 이상 | 수능 중위권 |

- 기본값은 "상급(특목고 수준)으로, 쉬운 문제를 내지 않는다"이다. 전 등급 공통: 지문 표현 그대로 옮기기 금지.

## 지문·세트 공통

- 지문 리드: "[1~5] 다음 글을 읽고 물음에 답하시오." (문항 번호 범위 표기)
- 배점은 발문 끝에 "[4점]" 형식.
- 같은 지문을 공유하는 문항은 지문을 1회만 싣는다.
