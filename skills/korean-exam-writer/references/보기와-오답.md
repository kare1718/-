# <보기> 작성 · 오답 설계

## <보기> 작성 원칙

<보기>는 작품을 단순히 설명·요약하는 해설문이 절대 아니다. 반드시 지문을 새롭게 읽게 만드는 해석 관점·감상 기준·비평적 렌즈로 기능해야 한다.

- ❌ 나쁜 예: "이 작품은 작은 생명에 대한 연민을 드러낸다."
- ✅ 좋은 예: "문학 작품에서 사소한 일상 행위는 타자의 고통을 인식하게 하는 계기가 될 수 있다. 이때 중요한 것은 행위 자체의 크기가 아니라, 그 행위를 뒤늦게 돌아보는 주체의 인식 변화이다. …"

**구조**: ① 문학 감상 원리 제시 → ② 그 원리가 작품 해석에서 어떤 기준인지 설명 → ③ 지문에 적용 가능한 관점 제시 → ④ 지문 내용 직접 요약·정답 노출 금지.

**정합성**: <보기> 본문은 지문의 사실·해석과 모순되면 안 된다. <보기>가 정답을 그대로 알려주면 안 되고, <보기>와 지문을 모두 종합해야만 정답이 판단되게 한다.

**5종 유형**: 1) 감상 원리형 2) 소재 관계형 3) 외부 작품 연계형 4) 학생 감상문 평가형 5) 선생님-학생 대화형

## 오답 설계 — 추론 오류 6종 (기본)

오답은 단순 사실 부정이 아니라 아래 오류 중 하나가 드러나게 설계한다. **선지 하나당 오류 1개만**, 한 문항의 오답 4개는 가급적 서로 다른 유형으로.

1. 주체와 객체의 전도
2. 원인과 결과의 혼동
3. 대립적 속성의 혼동
4. 정서·태도의 변화 과정 누락
5. 표현의 기능과 대상의 혼동
6. 부분 진술의 전체 일반화

## 오답 10패턴 (문학 확장판)

1. 앞부분은 맞지만 뒷부분 해석 방향이 틀린 선지
2. 소재는 맞지만 기능을 잘못 설정한 선지
3. 정서는 맞지만 강도를 과하게 설정한 선지
4. 두 작품 모두에 해당하는 내용을 "~와 달리"로 잘못 비교한 선지
5. <보기> 개념은 가져왔지만 지문 적용 방향이 틀린 선지
6. 반복/대비/전환/심화/해소/통합/확장/수렴 관계어를 미묘하게 잘못 적용한 선지
7. 가능성·바람·암시를 확신·단정으로 바꾼 선지
8. 일부 장면에만 해당하는 내용을 작품 전체 태도로 확장한 선지
9. 정서 발생은 맞지만 그 결과를 잘못 해석한 선지
10. 대상 기능은 맞지만 작품 전체 의미와의 연결을 과도하게 확장한 선지

## 함정어 (지문 근거로 판단 가능할 때만 사용)

- 범위: 처음부터 / 끝까지 / 항상 / 모두 / 전적으로 / 오직 / 일관되게
- 강도: 완전히 / 근본적으로 / 결정적으로 / 반드시 / 단정한다
- 관계: 대비 / 반복 / 전환 / 심화 / 해소 / 통합 / 확장 / 수렴 / 대립 / 대응 / 매개 / 환기 / 부각 / 형상화
- 결과: 극복한다 / 해소한다 / 단절한다 / 회복한다 / 통합한다 / 체념한다 / 정당화한다
- 비교: ~와 달리 / ~와 마찬가지로 / 반면에 / 공통적으로

**관계어 적용 주의**: 적용 대상을 정확히 명시한다.
- ✅ "자유의 이미지와 억압의 이미지가 반복적으로 대비된다."
- ❌ "자유와 억압이 반복된다."

## 선지 구성 밀도

한 선지 안에 다음 요소 중 최소 3개 이상을 넣는다: 구체적 대상 · 표현 방식 · 정서 · 인식 · 태도 · 관계 · 작품 전체 의미.

선지 작성 패턴 예:
- "(가)는 ~을/를 활용하여 ~을/를 드러내고 있고, (나)는 ~을/를 통해 ~을/를 강조하고 있다."
- "'시어A'는 ~을 의미하며, '시어B'와 대비되어 ~을/를 부각하고 있다."
